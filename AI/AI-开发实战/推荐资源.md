## 主推：ai-agents-from-zero（GitHub）

**链接：** https://github.com/didilili/ai-agents-from-zero
**在线阅读：** https://didilili.github.io/ai-agents-from-zero

**为什么推荐：**
- 2026 年最新，持续更新中
- 覆盖了你 `AI-开发实战` 文件夹的 **全部 8 个分区**
- 有 **可运行的源码** + **实战项目** + **面试题库**
- 概念部分你已经懂了（可以直接跳到实战）

**对照你的 8 个分区：**

| 你的分区 | 对应教程章节 |
|---|---|
| 01 - 环境搭建 | Ollama / API 配置 / Python 环境 |
| 02 - API 编程 | LangChain Model I/O / 多模型 API 调用 |
| 03 - RAG 开发 | RAG 章节 + 掌柜智库项目 |
| 04 - Agent 开发 | Agent 章节 + LangGraph + 电商问数项目 |
| 05 - Fine-tuning 实战 | 微调章节 + Llama-Factory 实操 |
| 06 - 部署与运维 | Docker / vLLM / 云端部署 |
| 07 - 工具链 | LangChain / LangGraph / MCP / Coze / Dify |
| 08 - Skill 开发 | MCP 章节 + Function Calling |
