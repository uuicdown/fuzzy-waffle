# 错误处理与状态码

## 是什么

API 调用可能失败，必须处理异常。

## 基础写法

```python
try:
    response = requests.post(url, headers=headers, json=data, timeout=60)
    response.raise_for_status()  # 状态码不是 200 时抛异常
    result = response.json()
except requests.exceptions.HTTPError as e:
    print(f"HTTP 错误：{e}")
    print(f"状态码：{response.status_code}")
    print(f"错误原因：{response.text}")  # ← 这行最重要
except requests.exceptions.Timeout:
    print("请求超时，网络或代理问题")
except requests.exceptions.ConnectionError:
    print("连接失败，检查网络")
```

## 常见状态码

| 状态码 | 含义 | 解决 |
|---|---|---|
| **200** | 成功 | — |
| **400** | 请求格式错 | 打印 `response.text` 看具体原因 |
| **401** | API Key 不对 | 检查 .env 文件 |
| **429** | 频率超限 | 等一下再试，或加延时 |
| **500** | 服务器错误 | 等一会重试 |

## 代理问题

```python
session = requests.Session()
session.trust_env = False  # 不读取系统代理，避免 SSL 报错
```
