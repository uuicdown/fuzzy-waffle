# 对话历史管理

## 是什么

API 是无状态的，每次调用都要传完整的 messages 数组。

## 手动维护历史

```python
messages = [
    {"role": "system", "content": "你是一个友好的助手。"},
    {"role": "user", "content": "我叫张三。"},
    {"role": "assistant", "content": "你好张三！"},
    {"role": "user", "content": "我叫什么名字？"}  # 当前问题
]

data = {
    "model": "deepseek-chat",
    "messages": messages
}
```

## 自动维护（多轮对话）

```python
messages = [{"role": "system", "content": "你是一个助手。"}]

def chat(user_input):
    messages.append({"role": "user", "content": user_input})
    response = requests.post(url, headers=headers, json={"messages": messages})
    reply = response.json()["choices"][0]["message"]["content"]
    messages.append({"role": "assistant", "content": reply})
    return reply

chat("你好")          # 第 1 轮
chat("我叫张三")      # 第 2 轮
chat("我叫什么？")    # 第 3 轮 → 还记得
```

## 历史太长时的裁减

```python
MAX_TOKENS = 4000

def trim(messages):
    while count_tokens(messages) > MAX_TOKENS and len(messages) > 2:
        messages.pop(1)  # 删最早的对话，保留 system prompt
    return messages
```
