# 参数详解

## temperature — 控制随机性

```
0     → 每次都选最高概率的词（确定、稳定）
0.7   → 默认值，有适度创造性
1.5   → 高随机，可能跑偏

代码生成 → 0.1
创意写作 → 0.8
日常对话 → 0.7（默认）
```

## max_tokens — 回答长度上限

```python
"max_tokens": 4096  # 回答最多 4096 个 token
```

注意：不是精确长度，是硬上限。到达这个值后 `finish_reason` 返回 `"length"`。

## top_p — 候选词范围

```python
"top_p": 0.9  # 只从前 90% 概率的词里选
```

通常调 `temperature` 就够了，`top_p` 保持默认 1 就行。

## stop — 停止词

```python
"stop": ["\n\n", "用户："]  # 遇到这些字符就停止生成
```

## stream — 流式开关

```python
"stream": False  # 一次性返回（默认）
"stream": True   # 逐 token 推送
```
