# 普通调用（非流式）

## 是什么

`stream=False`（默认值）。等模型全部算完，一次性返回完整结果。

## 代码

```python
data = {
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": False
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
content = result["choices"][0]["message"]["content"]
print(content)
```

## 特点

```
优点：代码简单，一次拿到完整结果
缺点：要等模型全部算完才能看到回应（可能等几秒）
适用：不需要即时反馈的场景（批量处理、后台任务）
```
