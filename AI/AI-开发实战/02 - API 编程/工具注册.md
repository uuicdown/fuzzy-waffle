# 工具注册（tools 参数）

## 是什么

在请求里告诉模型："你有这些工具可以用"。模型根据描述决定调哪个。

## 代码

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "calculate",
            "description": "做数学计算，支持加减乘除",
            "parameters": {
                "type": "object",
                "properties": {
                    "expression": {
                        "type": "string",
                        "description": "数学表达式"
                    }
                },
                "required": ["expression"]
            }
        }
    }
]

data = {
    "model": "deepseek-chat",
    "messages": messages,
    "tools": tools  # 注册工具
}
```

## 每个字段的用途

| 字段                      | 作用        | 注意                 |
| ----------------------- | --------- | ------------------ |
| `name`                  | 工具名，模型靠它选 | 不要用中文              |
| `description`           | 描述工具干什么   | **越清晰，模型选得越准**     |
| `parameters.properties` | 参数列表      | 每个参数也加 description |
| `required`              | 必填参数列表    | 缺了模型可能不传           |

## 和 Agent 配置的关系

**你的 Agent 配置界面里"添加工具"就是在填这个 JSON。** 只不过界面帮你做了翻译。
