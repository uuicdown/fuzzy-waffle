# MCP 是什么

## 一句话

**MCP = 工具的标准化接入协议。**

你之前手写 `tools = [...]` JSON 注册工具——MCP 把这个过程标准化了：一次开发 MCP Server，任何支持 MCP 的客户端都能用。

## 和 Function Calling 的关系

```
Function Calling = 底层的工具调用机制（你手写 tools JSON）
MCP = 上层的标准化协议（工具描述和通信的统一格式）
Agent = 最上层（规划 + 循环 + 工具调用）

不冲突，是层级关系。
```

## MCP 的三个核心能力

| 能力            | 作用       | 类比     |
| ------------- | -------- | ------ |
| **Tools**     | 可执行的操作   | API 接口 |
| **Resources** | 只读数据源    | 文件/数据库 |
| **Prompts**   | 预设的提示词模板 | 快捷指令   |
|               |          |        |

## 两种传输方式

```
stdio       → 本机运行，同一进程内通信（开发调试用）
streamable-http → 网络传输，可远程调用（生产环境用）
```
