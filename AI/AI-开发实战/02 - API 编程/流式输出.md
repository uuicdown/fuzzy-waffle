# 流式输出

## 是什么

`stream=True`。模型每算出一个 token 就推过来，实时显示，打字机效果。

## 代码

```python
data = {
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": True                # ① data 里开 stream
}

response = requests.post(
    url, headers=headers, json=data,
    stream=True                   # ② requests 也要开 stream
)

for line in response.iter_lines():
    if line:
        line_text = line.decode("utf-8")
        if line_text.startswith("data: "):
            content = line_text[6:]  # 去掉 "data: " 前缀
            if content == "[DONE]":
                break
            import json
            chunk = json.loads(content)
            delta = chunk["choices"][0]["delta"]
            if "content" in delta:
                print(delta["content"], end="", flush=True)
```

## 特点

```
优点：用户不用等，第一个 token 出来就能看到
缺点：代码比非流式复杂
注意：和 response_format 互斥，不能同时开
```
