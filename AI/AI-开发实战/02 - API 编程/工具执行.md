# 工具执行

## 是什么

模型只返回"调哪个工具、传什么参数"——**真正的执行是你代码做的。**

## 代码

```python
def execute_tool(name, args):
    if name == "calculate":
        expr = args["expression"]
        # 安全检查：只允许数字和运算符
        allowed = "0123456789+-*/(). "
        if not all(c in allowed for c in expr):
            return "错误：表达式包含非法字符"
        try:
            result = eval(expr)
            return f"计算结果：{result}"
        except Exception as e:
            return f"计算错误：{str(e)}"
    
    elif name == "get_weather":
        city = args["city"]
        # 这里可以换成真实的天气 API 调用
        return f"{city}今天晴天，22°C"
    
    return f"未知工具：{name}"
```

## 关键点

```
① 模型不干活，你的代码干活
② 参数 args 是 JSON，用 json.loads() 解析（如果还没解析的话）
③ 工具返回结果是字符串，要加回 messages 喂给模型
④ 加安全检查（防 eval 执行恶意代码）
```
