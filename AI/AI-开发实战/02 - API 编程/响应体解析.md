# 响应体解析

## 是什么

API 返回的 JSON 结构，从哪里取回答、看消耗。

## 完整结构
response.json()
```json
{
  "id": "chatcmpl-xxxx",
  "model": "deepseek-chat",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "你好！"              // ← 回答在这里
      },
      "finish_reason": "stop"           // 停止原因
    }
  ],
  "usage": {
    "prompt_tokens": 25,                // 输入 token 数
    "completion_tokens": 10,            // 输出 token 数
    "total_tokens": 35                  // 合计
  }
}
```

## 提取方式

```python
result = response.json()

content = result["choices"][0]["message"]["content"]  # 回答文本
usage = result["usage"]                                # token 消耗

# finish_reason 的判断
reason = result["choices"][0]["finish_reason"]
if reason == "stop":        # 正常结束
    print("回答完成")
elif reason == "length":    # 被 max_tokens 截断
    print("回答不完整，需要继续生成")
elif reason == "tool_calls":  # 要调工具
    print("模型决定调用工具")
```
