# 损失函数（Loss Function）

#核心机制 #损失函数

## 一句话
量化"模型的预测离真实答案有多远"的一个数字。训练的目标就是把这个数字不断压小。

## 工作原理

```
输入数据 → 神经网络前向传播 → 输出分数
                                 ↓
                           损失函数 → 一个数字（如 0.37）
                                 ↓
                     反向传播用这个数字来调参数
```

**损失函数不是神经元的计算流程**（那是前向传播）。它发生在前向传播结束之后——箭射完了，量一下离靶心多远。

## 常见损失函数

### 均方误差（MSE，Mean Squared Error）

```
L = (预测值 - 真实值)²
```

- 对小错误惩罚轻（0.1² = 0.01），对**大错误惩罚极重**（0.9² = 0.81）
- 适合：希望模型"尽量不要犯大错"的场景
- 缺点：对离群值（极端异常数据）过于敏感

### 平均绝对误差（MAE，Mean Absolute Error）

```
L = |预测值 - 真实值|
```

- 所有错误被**线性惩罚**（错 0.1 罚 0.1，错 0.9 罚 0.9）
- 适合：数据中有大量离群值，不想模型被极端值带偏

### Huber Loss（结合两者优点）

```
小误差 → 用 MSE（平方惩罚，平滑收敛）
大误差 → 用 MAE（线性惩罚，不受离群值影响）
```

中间设一个阈值 δ 作为切换点。

## 损失函数的选择决定训练行为

- 用 MSE → 模型会极度避免大错误，但可能被极端离群值带偏
- 用 MAE → 模型对所有错误一视同仁，但收敛较慢
- 用 Huber → 两边好处都要，但多一个超参数 δ 要调

## 降维映射

> 射箭：前向传播是拉弓射箭的过程。损失函数是箭射出去之后，你去靶子上量距离的动作。你不需要重新射一箭才知道偏了多远——你量一量，下一箭就知道怎么调了。

## 🧪 摸底自测

#### Q1（入门）
> Cross-Entropy Loss 在 LLM 训练中是怎么用的？模型的输出和真实标签各是什么形式？

<details>
<summary>点击查看解答思路</summary>

模型输出：词表上每个 token 的概率分布（100K 维向量）。真实标签：正确答案的 One-Hot 向量（正确 token 位置=1，其他=0）。Loss = -log(P(正确 token))——模型分配给正确 token 的概率越接近 1，Loss 越小。
</details>

#### Q2（进阶）
> 如果模型对正确答案给出的概率是 0.01（非常低），Loss 大约是多少？这个数字的含义是什么？

<details>
<summary>点击查看解答思路</summary>

Loss = -log(0.01) ≈ 4.6。含义：模型对自己的错误"非常自信"——把高概率分配给错误 token，给正确 token 极低概率。这个高 Loss 信号会强烈地驱动模型调整参数。
</details>
