# 规模缩放定律（Scaling Law）

> ✅ 已学习 — 2026-05-18
>
> 模型性能随参数、数据、算力增长的可预测规律。

---

## 一句话本质

**模型的效果 = f(参数量, 数据量, 算力)。三者同步增长时性能可预测地提升，但进入收益递减区后需要新方案（MoE）。**

---

## 核心发现（OpenAI, 2020）

```
模型 Loss ≈ 1 / (参数量^α × 数据量^β × 算力^γ)

简单说：参数量翻倍、数据量翻倍、算力翻倍
        → Loss 稳定下降 → 效果稳定提升
```

当时的影响：**大家疯狂堆参数、堆数据、堆 GPU。**

```
GPT-1 (2018)：   0.1B 参数 /  5GB 数据
GPT-3 (2020)： 175B 参数 / 570GB 数据
GPT-4 (2023)：   推测 ~1.8T 参数
```

---

## Scaling Law 撞墙了（2024-2025）

不是"失效"了——是进入了**收益递减区**：

```
GPT-3 → GPT-4：参数翻 10 倍，效果提升明显
GPT-4 → GPT-5：参数翻倍，效果提升变少，成本翻倍

关键问题：
  算力成本增长 > 效果增长
  堆参数的性价比在下降
```

**MoE 是当前对这个问题的核心解：**

```
Dense 模型：堆参数 → 全部参数都参与计算 → 成本线性增长
MoE 模型：堆总参数 → 每次只激活一小部分 → 效果增长，成本微增
```

---

## Chinchilla 定律（DeepMind, 2022）

一个重要的修正发现：

```
Scaling Law 不仅看参数，还要看"参数 vs 数据"的比例。

Chinchilla 发现：大多数模型参数太多、数据太少。
  最优比例 ≈ 20 token / 1 参数
  
  例如 70B 模型 → 需要至少 70B × 20 = 1.4T token
  很多模型训练的数据量没达到这个比例 → 参数白堆了
```

---

## 当前共识

```
① Scaling Law 没有失效，但进入了收益递减区
② 堆参数的性价比在下降
③ MoE 是当前最主流的解（效果看总参数，成本看激活参数）
④ Chinchilla 比例提醒：数据和参数要同步增长
⑤ 下一个方向可能是"推理时计算"（o1/R1 的思维链策略）
```

## 🧪 摸底自测

#### Q1（入门）
> Scaling Law 的核心发现是什么？

<details>
<summary>解答</summary>

模型性能随参数、数据、算力同步增长可预测地提升。参数×数据×算力 → 效果提升。
</details>

#### Q2（进阶）
> 为什么说 Scaling Law "撞墙了"？MoE 怎么应对？

<details>
<summary>解答</summary>

不是失效，是收益递减——参数翻倍的效果提升不如成本翻倍。MoE 的应对：堆总参数但不激活全部，效果增长但成本微增。
</details>
