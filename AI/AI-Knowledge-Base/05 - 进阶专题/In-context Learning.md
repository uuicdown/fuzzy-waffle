# 上下文学习（In-context Learning / Few-shot / Zero-shot）

> ✅ 已学习 — 2026-05-18
>
> 不训练模型，只在 Prompt 里放几个例子，模型就自动"学会"了任务。
> 用完就忘，不占模型空间。

---

## 一句话本质

**ICL = 模型不更新权重，只靠 Attention 在推理时捕捉 Prompt 中的模式来完成任务。**

SFT 改权重（永久记住），ICL 给例子（临时学会）。

---

## 三种方式

| 方式 | 例子数 | 效果 | 场景 |
|---|---|---|---|
| **Zero-shot** | 0 个 | 靠指令让模型执行新任务 | "把这句话翻译成英文：" |
| **Few-shot** | 2-3 个 | 给例子让模型学到模式 | 需要固定输出格式时 |
| **Many-shot** | 10-100 个 | 接近微调效果 | 不便于微调但需要高质量输出时 |

### Zero-shot

```
"把下面这句话翻译成英文：今天天气真好"
→ "The weather is nice today."

不给例子，只靠指令。模型能执行是因为 Pre-training 时见过类似格式。
```

### Few-shot

```
"法语翻译：
  hello → Bonjour
  goodbye → Au revoir
  thank you → ______"
→ "Merci"

模型从两个例子中看到了"翻译模式"，第三个自然跟着来。
```

### Zero-shot vs Few-shot 效果差距

```
复杂任务（如情感分析、格式提取）：
  Zero-shot：准确率 ~60%
  Few-shot（3 个例子）：准确率 ~85%
  
简单任务（如翻译、摘要）：
  Zero-shot 和 Few-shot 差距不大
```

---

## ICL 和 SFT 的对比

| 维度 | ICL（上下文学习） | SFT（监督微调） |
|---|---|---|
| **改变模型权重** | ❌ 不改变 | ✅ 更新权重 |
| **数据需求** | 2-3 个例子 | 几千条标注数据 |
| **成本** | 几乎为零 | 训练 + 存储 |
| **永久性** | 用完就忘 | 永久记住 |
| **适合场景** | 快速试错、临时任务 | 长期固定任务 |

---

## 🔑 关键认知

ICL 的底层机制仍然有争议，但有一个公认的核心洞察：

**模型在 Pre-training 阶段已经见过了几乎所有模式——ICL 只是在推理时唤醒了这些模式。**

```
你给模型 2 个翻译例子 → 不是模型"现学"了翻译
→ 是 Pre-training 时它已经见过上亿条翻译数据
→ 你的 2 个例子只是"提示"它当前上下文是翻译任务
→ 它从记忆库里调出翻译能力
```
