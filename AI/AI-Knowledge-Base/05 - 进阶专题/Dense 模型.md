# Dense 模型（稠密模型）

> ✅ 已学习 — 2026-05-18
>
> 推理时所有参数全部激活的传统 Transformer 模型。和 MoE 相对。

---

## 一句话

**Dense = 全部参数都参与计算。你学过的 GPT、Claude、Llama 都是 Dense 模型。**

```
Dense 模型（如 Llama 3 70B）：
  总参数：70B
  每次激活：70B ← 全部
  
MoE 模型（如 DeepSeek-V3）：
  总参数：671B
  每次激活：37B ← 只激活 top-2 专家
```

## 特点

| 维度         | Dense  | MoE             |
| ---------- | ------ | --------------- |
| 结构         | 单一 FFN | 多个专家 + Router   |
| 总参数 = 激活参数 | ✅ 是    | ❌ 否（总参数 > 激活参数） |
| 训练稳定性      | ✅ 高    | ⚠️ 有专家失衡问题      |
| 推理显存       | 相对小    | 大（全部专家都要加载）     |
| 效果/成本比     | 线性增长   | 更优（花小钱办大事）      |
