# 神经网络（Neural Network）

#概念定义 #神经网络

## 一句话
受生物神经元启发的计算模型：接收一组输入，加权求和，经过激活函数判断是否"激活"后输出。无数个这样的基本单元连接成网络，就能拟合任意复杂的函数。

## 单个神经元的数学公式

```
output = activation( w₁x₁ + w₂x₂ + ... + wₙxₙ + b )
```

拆成三步理解：

1. **加权求和**：每个输入 x 乘上对应的权重 w，全部加起来，再加一个偏置 b
   - 就像买菜算总价：苹果 3元×2斤 + 香蕉 5元×1斤 + 袋子1元 = 12元
2. **激活函数**：判断求和的结果够不够强
   - 最常见：ReLU（小于 0 输出 0，大于 0 原样输出）
   - 相当于一个门：信号不够就关门，够就放行
3. **输出**：一个数字（激活值或 0）

## 关键概念

### 权重（Weight，w）
控制每个输入的重要性。权重越大，这个输入对最终决策的影响越大。

### 偏置（Bias，b）
控制神经元的"敏感度阈值"。偏置大 → 更容易激活；偏置小 → 更难激活。

### 激活函数（Activation Function）
让神经网络"有深度"的唯一原因。如果不加激活函数，叠多少层都等价于一层（线性变换的复合还是线性变换）。

**常见激活函数**：
- **ReLU**：`max(0, x)` — 当前主流，简单有效
- **Sigmoid**：将值压缩到 0~1 之间 — 用于二分类输出层
- **Tanh**：将值压缩到 -1~1 之间 — 早期常用

## 一层 vs 多层

**一层（单层感知机）**：只能处理线性可分问题（一条直线能切开的分类）。
- 比如：按"邮件中含'免费'的次数"和"发件人是否在通讯录"判断垃圾邮件
- 局限：学不会 XOR 问题——因为四个点在对角线上，无法一条直线分割

**多层（多层感知机，MLP）**：先切多条直线，再组合成非线性边界。
- 第一层：每个神经元从不同角度切一条直线
- 第二层：把第一层的结果再做一次判断
- 层数越多，能拟合的边界越复杂

## 信息流动

```
输入 → [权重·输入 + 偏置] → 激活函数 → 输出 → 下一层
  ↑                                     ↓
  前向传播（从前往后流）          反向传播（从后往前调参数）
```

## 认知盲区

❌ 神经网络在"思考" → ✅ 神经网络在做纯数学运算：加权求和×激活函数，层层传递。没有意识，只有计算。

❌ 层数越多一定越好 → ✅ 层数越多，能拟合的边界越复杂，但也越容易过拟合（背死数据而非学通规律）。

## 降维映射

> 一个神经元 = 公司前台，只回答"是/否"
> 一层神经元 = 一个委员会，每人从不同角度判断
> 多层网络 = 委员会 → 上级委员会 → 最高决策层，逐层抽象
