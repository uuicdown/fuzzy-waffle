# 专家系统（Expert System）

> 符号主义（Symbolism）的核心产物——AI 第一波浪潮的技术代表。
> 
> 与神经网络"从数据中学习"不同：专家系统的知识是**人类专家手写的 if-then 规则**。

---

## 一句话定义

**专家系统 = 知识库（规则集）+ 推理引擎（规则匹配器）**

不是"训练出来的"，是"写出来的"。

---

## 工作原理

```
三层架构：

用户输入  →  推理引擎  →  知识库
（症状）      ↓          （规则）
           解释器      IF 发热 AND 咳嗽 THEN 感冒
           匹配器      IF 感冒 AND 发热>3天 THEN 血检
           冲突解决    IF ... THEN ...
              ↓
          诊断结果 + 置信度
```

**推理引擎**干三件事：
1. **匹配**：当前条件匹配了哪些规则
2. **冲突解决**：多条规则同时满足时选哪条（按置信度/优先级）
3. **链式推理**：一条规则的结论可能成为另一条规则的前提

**两种推理方向：**

```
前向推理（Forward Chaining）：数据驱动
  事实 1：患者发热
  事实 2：患者咳嗽
  → 匹配规则 1：IF 发热 AND 咳嗽 THEN 感冒
  → 结论：感冒

反向推理（Backward Chaining）：目标驱动
  目标：判断患者是不是得病 X
  → 反查：要得病 X 需要满足什么条件？
  → 条件 A 和条件 B？
  → 检查条件 A 是否满足 → 检查条件 B 是否满足
```

## 巅峰与崩溃

### 巅峰（1980s）

| 系统 | 领域 | 影响 |
|---|---|---|
| **MYCIN** | 细菌感染诊断 | 正确率超过部分人类专家，约 500 条规则 |
| **XCON** | DEC 计算机配置 | 每年节省 4000 万美元，约 10,000 条规则 |
| **DENDRAL** | 化学分子结构解析 | 质谱分析，AI 早期最成功的科学应用 |
| **PROSPECTOR** | 矿产勘探 | 发现了价值数亿美元的钼矿 |

1980s 中期，日本甚至启动了 **"第五代计算机"** 计划——举国之力搞符号主义 AI。

### 崩溃（1990s）

原因只有一个：**知识获取瓶颈（Knowledge Acquisition Bottleneck）**

```
写 100 条规则：  2 个专家 × 3 个月      ← 还能接受
写 1,000 条规则： 5 个专家 × 2 年       ← 开始吃力
写 10,000 条规则： 10 个专家 × 10 年    ← 不可能完成

更致命的问题：
  规则 A：IF 杯子是玻璃的 AND 掉在地上 THEN 会碎
  规则 B：IF 杯子有保护套 THEN 不会碎
  规则 C：IF 掉在沙地里 THEN 不会碎
  ...
  常识是无穷的，规则永远写不完
```

加上同时期 **神经网络复兴**（尤其是反向传播被广泛采用），AI 从"让人类教机器"转向了"让数据教机器"，专家系统退出历史舞台。

## 降维映射

**专家系统 = 一本极其详尽的法律条文**

```
法律条文：IF 闯红灯 THEN 罚款 200元
专家系统：IF 发热 AND 咳嗽 THEN 感冒置信度 80%

两者的共同优点：
  - 完全透明，可以逐条审查
  - 结论可追溯（"根据规则 247 条判定"）

两者的共同弱点：
  - 法律没写的案子就判不了
  - 每增加一条新法律都要人手动写
```

**对比神经网络：**

```
法律条文（专家系统）：精确、透明、昂贵、脆弱
十年经验法官（神经网络）：模糊、黑箱、便宜（自动学习）、泛化

→ 这不是谁取代谁——最顶级的司法系统是"法条 + 法官"配合
   AI 的未来也是专家系统 + 神经网络的混合
```

## 在现代 AI 中的回声

虽然纯专家系统不再主流，但它的思想以不同形式活在今天的 AI 中：

| 现代技术 | 与专家系统的关系 |
|---|---|
| **Prompt Engineering** | 人类用自然语言写下规则——本质上是"用 LLM 作为推理引擎的软性专家系统" |
| **Function Calling** | 把外部工具的逻辑封装成"IF 用户需要查天气 THEN 调用 API" |
| **Knowledge Graph** | 结构化的关系和规则的图谱，供 LLM 推理时查询 |
| **RAG** | 把外部知识库（类似专家系统的知识库）挂到大模型上用 |
| **GraphRAG** | 显式的知识结构化 + LLM 推理能力 = 专家系统 + 神经网络的混合体 |

---

## 关键速记

- **年代**：1960s-1990s，巅峰在 1980s
- **本质**：知识是写出来的，不是学出来的
- **核心瓶颈**：知识获取 —— 规则需要人类专家逐条编写
- **死亡原因**：常识的无穷性 + 神经网络复兴
- **遗产**：可解释性、规则推理、知识表示——这些思想在现代 AI 中依然活跃

## 🧪 摸底自测

#### Q1（入门）
> 专家系统和神经网络（LLM）的知识来源有什么本质区别？

<details>
<summary>点击查看解答思路</summary>

专家系统的知识是"写出来"的——人类专家手写 if-then 规则。神经网络的知识是"学出来"的——从海量数据中自动统计学习。一个是符号主义（显式规则），一个是连接主义（隐式权重）。
</details>

#### Q2（进阶）
> 专家系统在 1990 年代被神经网络取代，根本原因是什么？不是"不够聪明"，而是？

<details>
<summary>点击查看解答思路</summary>

知识获取瓶颈：写 100 条规则要几个月，扩展到 10000 条几乎不可能。常识是无穷的（"玻璃杯掉地上会碎" "但掉沙地里不会" "但有保护套也不会"...），规则永远写不完。
</details>

#### Q3（思考）
> 现代 AI 中哪些技术其实有"专家系统思想"的影子？

<details>
<summary>点击查看解答思路</summary>

Prompt Engineering（用自然语言写"规则"），Function Calling（IF 条件→调用工具），RAG（外部知识库 + 检索），GraphRAG（结构化知识 + LLM 推理）。专家系统没死，它的思想以新的形式活着。
</details>
