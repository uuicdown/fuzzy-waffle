# 经验系统（行为主义与强化学习）

> 行为主义（Actionism / Behaviorism）——AI 的第三大学派。
>
> 核心信念：智能不是"写出来的"（符号主义），也不是"从数据中学出来的"（连接主义）——而是**在环境互动中通过试错和反馈逐步积累策略的过程。**

> ⚠️ "经验系统"并非 AI 领域的标准术语。本笔记将其解读为行为主义/强化学习（Reinforcement Learning）的统称——这是你在提到"经验系统"时最可能指向的概念。

---

## 一句话本质

**知识 = 从试错互动中积累的策略**

| 核心循环 | 含义 |
|---|---|
| Agent（主体）| 做决策的 AI |
| Action（动作）| AI 在环境中的一步操作 |
| Environment（环境）| 被交互的对象（游戏、现实世界、对话者） |
| Reward（奖励信号）| 环境的反馈，告诉 AI 这一步好不好 |
| State（新状态）| 环境在执行动作后变成的新局面 |

---

## 三大学派的对比

| | 符号主义（专家系统） | 连接主义（SLM/LLM） | 行为主义（经验系统/RL） |
|---|---|---|---|
| **知识来源** | 专家手写规则 | 从静态数据中统计学习 | 从动态交互中试错积累 |
| **数据需求** | 不需要数据，需要专家时间 | 需要海量静态数据 | 需要大量交互和反馈 |
| **行为质量** | 精确但脆弱 | 模糊但泛化 | 在特定领域可以超人类 |
| **代表成就** | MYCIN 诊断系统 | GPT-4 大语言模型 | AlphaGo / RLHF |
| **智能的本质** | 逻辑推理 | 模式匹配 | 策略优化 |

## 强化学习的核心机制

### 基础框架

```
         Agent
      ┌───┴───┐
      │ 策略 π  │  ← 当前状态下应该做什么动作
      └───┬───┘
          │ 动作 a
          ▼
    ┌──────────┐
    │ 环境     │ ← 接受动作，返回新状态 s' + 奖励 r
    │ 奖励信号  │
    └──────────┘
          │
          ▼
  记录 (s, a, r, s')
  用这个经验更新策略 π
```

### Trial-and-Error 而非 Supervised Learning

```
监督学习（LLM 的训练方式）：
  输入 → 你期望的输出（有标准答案）
  模型改 → 让输出接近标准答案

强化学习（经验系统的方式）：
  动作 → 环境只给你一个"好坏评分"，不告诉你正确答案是什么
  模型改 → 让未来累计的奖励最大
  你甚至不知道刚才那个动作如果换一种方式会怎样
```

**降维映射：**

```
监督学习 = 有标准答案的考试
  题目：2+2=？
  正确答案：4
  你回答错误 → 知道该往哪个方向改

强化学习 = 打游戏
  你按下按钮 → 屏幕上多了一分
  你按另一个 → Game Over
  评分有了，但"下一次该按哪个按钮才对"？
  → 你得靠自己慢慢摸索策略
```

## 经验系统的三次高潮

### 第一次：TD-Gammon（1992）

AI 自学了国际双陆棋（Backgammon），通过与自己对弈数百万局。
达到人类世界冠军级水平。

**突破点**：证明了"不需要人类知识，纯靠自对弈和奖励信号就能产生超人类策略"。

### 第二次：AlphaGo / AlphaZero（2016-2019）

AlphaGo 击败李世石，震惊世界。

```
核心创新：
  1. 经验系统（RL 自对弈） + 连接主义（神经网络） → 混合
  2. 不需要人类棋谱 → AlphaZero 版本纯自学
  3. 从围棋扩展到象棋、将棋——通用方法

更惊人的是什么？
  AlphaGo 下出了人类围棋史上从未出现过的棋着（"第 37 手"）
  → 智能可以超越人类"知识"的边界
  → 这是符号主义和连接主义做不到的
```

### 第三次：RLHF（2022-至今）

**当前对 LLM 影响最大的经验系统应用。**

```
你学过的 Pre-training（连接主义）
  → 模型有巨大知识储备但行为不规范
       ↓
你学过的 SFT（连接主义的扩展）
  → 模型学会回答问题，但倾向于迎合而非真实
       ↓
RLHF（经验系统）
  → 人类给模型的回答打分（好/差）
  → 模型不是背答案，而是学会"什么样的回答是人类喜欢的"
  → 区别：
      SFT = 背标准答案
      RLHF = 理解评分标准（可以自己写新答案）
```

**RLHF 的运作方式：**

```
Step 1：收集人类偏好
  AI 对同一个问题生成 2-4 个回答
  人类排序：A > C > B > D

Step 2：训练奖励模型（Reward Model）
  一个独立的模型，任务：预测人类会给这个回答打几分
  本质上是"把人类的评分标准数字化"

Step 3：用强化学习优化大模型
  大模型每次生成回答 → 奖励模型打分 → 大模型调整策略
  目标是让奖励模型给的分越来越高
  → 模型学会了"人类喜欢的说话方式"
```

## 经验系统的独特性质

### 性质 1：超越训练数据的能力

```
AlphaGo 下出人类历史上没有出现过的棋着
RLHF 后的模型能写出 SFT 数据里从没出现过的表达方式

→ 经验系统不是在模仿过去，是在"搜索最优策略"
→ 这是它和连接主义的分水岭
```

### 性质 2：对环境的依赖

```
符号主义：知识在规则里，环境不怕变
连接主义：知识在权重里，静态数据集不怕变
行为主义：知识在策略里，策略高度依赖特定环境

换一个环境 → 策略可能完全失效
AlphaGo 不能下象棋，RLHF 模型换个语言可能崩
```

### 性质 3：探索 vs 利用的永恒矛盾

```
探索：尝试没做过的动作（可能发现更好的策略）
利用：重复已知好的动作（拿到稳定的奖励）

太探索 → 浪费算力，永远在试错
太利用 → 陷入局部最优，永远找不到更好的策略
```

**这是 RL 最难的核心问题，至今没有完美解法。**

## 三大学派的现在

```
今天的 AI 产品，没有任何一个只用单一学派：

GPT-4 = 连接主义产物 + 行为主义对齐（RLHF）
         ↑ 核心能力       ↑ 行为规范

AlphaGo = 行为主义框架 + 连接主义内核
           ↑ 学习策略       ↑ 神经网络拟合价值函数

ChatGPT + RAG = 连接主义 + 符号主义思想
                 ↑ 核心能力    ↑ 显式检索外部知识（类似规则查询）
```

**未来趋势：三大学派的深度融合。**

---

## 关键速记

- **核心机制**：Agent → 动作 → 奖励 → 修改策略 → 循环
- **关键区别**：没有正确答案，只有好坏评分
- **三次高潮**：TD-Gammon (1992) → AlphaGo (2016) → RLHF (2022)
- **现代应用**：RLHF（LLM 对齐）、推荐系统、自动驾驶决策
- **核心矛盾**：探索 vs 利用
- **"经验"的含义**：不是在数据库里存数据，是在"一次次互动中积累的行为策略"

## 🧪 摸底自测

#### Q1（入门）
> 强化学习（经验系统）和监督学习（LLM 的训练方式）的核心区别是什么？

<details>
<summary>点击查看解答思路</summary>

监督学习有标准答案（"正确答案是 4"），模型往答案方向改。强化学习只有好坏评分（"得了一分""Game Over"），没有"正确答案"——模型要通过试错自己摸索策略。
</details>

#### Q2（进阶）
> RLHF 是经验系统思想在现代 LLM 中的应用。它的三步流程是什么？

<details>
<summary>点击查看解答思路</summary>

Step 1：人类对模型多个回答进行偏好排序 → Step 2：训练一个奖励模型（Reward Model）来预测人类的打分偏好 → Step 3：大模型每次生成回答后由奖励模型打分，通过强化学习调整策略，让分数越来越高。
</details>

#### Q3（思考）
> AlphaGo 下出了人类围棋史上从未出现过的棋着。这说明了经验系统的什么独特性质？

<details>
<summary>点击查看解答思路</summary>

经验系统不是在"模仿过去"，而是在"搜索最优策略"。它有可能超越人类知识的边界——这是符号主义（规则写死）和连接主义（从静态数据中学习）都做不到的。
