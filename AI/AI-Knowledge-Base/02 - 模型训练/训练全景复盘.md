## 四步的定位

### 1. Pre-training：从零到"有语言能力"

| 项目 | 内容 |
|---|---|
| **输入** | 互联网原始文本（Common Crawl + 代码 + 书籍） |
| **任务** | Next Token Prediction（猜下一个词） |
| **数据量** | ~3 万亿 token |
| **算力占比** | 95-97% |
| **产出的模型** | "续写机器"——有语言规律和知识，但不会回答问题 |
| **关键挑战** | 数据筛选、配比、涌现控制、分布式训练 |

### 2. SFT：从"续写"到"回答问题"

| 项目 | 内容 |
|---|---|
| **输入** | 人工标注的指令-回答对（1万-10万条） |
| **任务** | 监督学习——模仿标准回答格式 |
| **数据量** | ~1-10 万条 |
| **算力占比** | 2-3% |
| **产出的模型** | 能回答问题，但风格单一、可能过拟合到格式 |
| **关键风险** | 格式过拟合、知识遗忘、幻觉固化 |

### 3. RLHF：从"会回答"到"回答得好"

| 项目 | 内容 |
|---|---|
| **输入** | 人类对多个回答的偏好排序 |
| **任务** | 强化学习——学会"什么样的回答更好" |
| **数据量** | 几十万条偏好标注 |
| **算力占比** | 0.5-1% |
| **产出的模型** | 符合人类偏好的对话助手 |
| **关键特点** | 保留创造性、学会评分标准而非背答案 |

### 4. Fine-tuning（含 LoRA）：在已有模型上做垂直优化

| 项目 | Full FT | LoRA |
|---|---|---|
| **更新参数** | 全部（70B） | A×B 适配器（~几万） |
| **训练显存** | ~1 TB（13× H100） | ~150 GB（1× H100） |
| **存储每个任务** | 140 GB | 2-20 MB |
| **适用场景** | 极致效果、单一任务 | 多任务部署、资源有限 |

## 核心反直觉点总结

### 1. 算力倒挂

```
最重的一步（Pre-training，95%）产出的是"最没用"的模型（不会回答问题）
最轻的一步（RLHF，0.5%）产出的是"最好用"的模型（对齐人类偏好）
```

### 2. 数据量倒挂

```
Pre-training：3 万亿 token（整个互联网）→ 一次过，不重复
SFT：          1 万条（几百页文档）→ 小心翼翼防过拟合
RLHF：         几十万条偏好标注→ 用"比较"而非"答案"来训练
```

### 3. SFT 不是"教知识"，是"教格式"

```
很多人都以为 SFT 是让模型学新知识。
实际上 Pre-training 已经把知识学完了。
SFT 只是教会模型"这些知识应该以什么格式输出"——相当于家教教的是"答题卡怎么填"，不是"这道题怎么做"。
```

### 4. LoRA 的"小而有效"

```
全参数微调要改 70B 参数（140GB），LoRA 只改几万参数（2-20MB）。
但效果接近——因为 Fine-tuning 要做的改变信息量很小，
不需要 70B 维度来承载，"低秩"就够了。
```

## 训练流水线的决策树

```
你想做什么？
│
├── 让模型掌握新知识？
│   └── Pre-training（从零）或 Fine-tuning（在已有上增量）
│
├── 让模型学会回答问题？
│   └── SFT
│
├── 让模型回答更符合人类偏好？
│   └── RLHF
│
├── 让模型在特定领域变专家？
│   ├── 有足够算力 → Full Fine-tuning
│   └── 算力有限 / 多任务 → LoRA / QLoRA
│
└── 让模型知道新信息但不想改模型？
    └── RAG（开卷考试，不改模型）
```

## 关键数字速记

| 数字 | 含义 |
|---|---|
| **95%** | Pre-training 占整个训练的计算量 |
| **3 万亿** | Pre-training 消耗的 token 数 |
| **1 万-10 万** | SFT 需要的数据条数 |
| **140 GB** | 70B 模型 FP16 的权重体积 |
| **20 MB** | LoRA 适配器的存储体积（r=8） |
| **13× H100** | Full FT 70B 需要的最少显卡数 |
| **1× H100** | LoRA 70B 需要的最少显卡数 |
| **1× RTX 4090** | QLoRA 70B 需要的最少显卡数 |
