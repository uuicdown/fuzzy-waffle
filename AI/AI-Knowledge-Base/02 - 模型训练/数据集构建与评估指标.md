## 数据集构建流程

```
原始数据（Common Crawl / 代码 / 书籍）
  → 清洗（去重、语言检测、格式标准化）
  → 质量打分（用一个小模型判"质量高低"）
  → 配比调整（文本:代码:数学 = 70:15:10）
  → 输出训练数据集
```

---

## 评估指标

| 指标 | 衡量什么 | 训练中 | 推理时 |
|---|---|---|---|
| **Loss** | 模型预测和真实的差距 | ✅ 最常用 | ❌ |
| **Perplexity** | 模型对下一个 token 的"困惑程度" | ✅ | ❌ |
| **Benchmark** | 标准化测试集（MMLU/GSM8K） | ⬜ 偶尔 | ✅ 最常用 |

## 常用 Benchmark

```
MMLU：57 个学科的多选题 → 衡量知识广度
GSM8K：小学数学题 → 衡量推理能力
HumanEval：编程题 → 衡量代码能力
```
