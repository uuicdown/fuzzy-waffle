### 一、DIRB是什么？为何必备？

DIRB（DIR Browser）是一款轻量级 **开源 [Web目录扫描器](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=1&q=Web%E7%9B%AE%E5%BD%95%E6%89%AB%E6%8F%8F%E5%99%A8&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiJXZWLnm67lvZXmiavmj4_lmagiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.-NYyD4OB0hwrHZmgqz0fZYF-qCOIn3kEmeoi-z05lw4&zhida_source=entity)** 。它通过发送HTTP请求，暴力探测目标站点的隐藏目录和文件。核心优势：

- ✅ **极简高效** ：纯C语言编写， [多线程并发](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=1&q=%E5%A4%9A%E7%BA%BF%E7%A8%8B%E5%B9%B6%E5%8F%91&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiLlpJrnur_nqIvlubblj5EiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.RtTwqlu15B1jtfE50Sv5c9mnMmU6XsZjsvycU8jOj8A&zhida_source=entity) （速度碾压GUI工具）
- ✅ **灵活定制** ：支持 [自定义字典](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=1&q=%E8%87%AA%E5%AE%9A%E4%B9%89%E5%AD%97%E5%85%B8&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiLoh6rlrprkuYnlrZflhbgiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.xKLdifE9MbmIJZneV_ucL40wjuy9I0NPrUOyEEVAlz8&zhida_source=entity) 、请求头、代理、延时
- ✅ **精准识别** ：通过 [响应码](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=1&q=%E5%93%8D%E5%BA%94%E7%A0%81&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiLlk43lupTnoIEiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.K3W9RcUY_-kUddkMTzgFnJ4Tf1s1pF5IzhHOCT9o54I&zhida_source=entity) （200/403/401）智能判断目录存在性

### 四、高阶玩法：自定义字典与智能扫描

**1\. 切换字典（默认路径： `/usr/share/dirb/wordlists/` ）**

```
dirb http://target.com -w /path/to/custom_dict.txt
```

推荐字典：

- `common.txt` ：基础目录名
- `big.txt` ：综合路径（覆盖CMS常见路径）
- `mutations.txt` ： [变体组合](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=1&q=%E5%8F%98%E4%BD%93%E7%BB%84%E5%90%88&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiLlj5jkvZPnu4TlkIgiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.TY_TH5fJqUaa9BEh8SN0JvOfzT5wNbALW19CMKAGcdk&zhida_source=entity)

**2\. 多线程加速（默认8线程）**

```
dirb http://target.com -t 20  # 暴力提速！
```

**3\. 敏感文件精准探测**

```
dirb http://target.com -X .bak,.zip,.sql  # 扫描备份/数据库文件
```

### 五、实战案例：挖洞直通车

**场景** ：某银行网站存在未授权后台漏洞

**挖洞步骤** ：

```
# 步骤1：使用自定义字典+认证头  
dirb http://target.com -w admin_paths.txt -H "Cookie: auth_token=xxx" -o admin_scan.txt  

# 步骤2：结果中定位响应码200的路径  
http://target.com/admin/  (200)  → 跳转后台入口！
```
![](https://pic1.zhimg.com/v2-0ac630f66f1da1469a511bad9e163786_1440w.jpg)

**成果** ：发现未授权访问的管理后台 → 高危漏洞到手！

![](https://pic2.zhimg.com/v2-f6773ba93784081eb601ca195663f5d1_1440w.jpg)

扫描报告样例

**样例报告解读** ：

- 输出的第一部分告诉我们扫描的 `URL_BASE` ，这只是我们提供给工具的 `URL` 。它还显示了该工具使用的 `wordlist` 文件的位置，其中包含将在暴力攻击期间测试的常见页面名称。在这种情况下，该工具使用工具附带的默认单词列表，位于 `/usr/share/dirb/wordlists/common.txt` 。
- 以 `+` 号开头的行是扫描的结果。在本例中， `DIRB` 发现了两个 URL。

### 六、DIRB vs 御剑：优势解析

| 功能 | DIRB | 御剑 |
| --- | --- | --- |
| 自定义请求头 | ✅ 支持（-H参数） | ❌ 不支持 |
| 认证绕过 | ✅ Base64/Cookie轻松突破 | ❌ 无解决方案 |
| 命令行集成 | ✅ 完美适配自动化脚本 | ✅ 主要为GUI， [命令行](https://zhida.zhihu.com/search?content_id=260145236&content_type=Article&match_order=2&q=%E5%91%BD%E4%BB%A4%E8%A1%8C&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTE3MjY5NTQsInEiOiLlkb3ku6TooYwiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNjAxNDUyMzYsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MiwiemRfdG9rZW4iOm51bGx9.xJutgRYoThLYfpYA-iFm1z0cGld4qsWMuvq5wgR1ja4&zhida_source=entity) 功能有限 |
| 资源占用 | ✅ 极低（纯命令行） | ❌ 高内存占用 |
