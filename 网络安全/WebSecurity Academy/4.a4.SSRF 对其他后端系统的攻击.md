# 在某些情况下，应用服务器能够与用户无法直接访问的后端系统交互。这些系统通常拥有不可路由的私有 IP 地址。后端系统通常受网络拓扑保护，因此安全防护通常较弱。在许多情况下，内部后端系统包含敏感功能，任何能够与系统交互的人都可以无需身份验证即可访问。

# 在前面的例子中，假设后端 URL `http://192.168.0.68/admin` 有一个管理接口。攻击者可以提交以下请求以利用 SSRF 漏洞，并访问管理接口：

```
POST /product/stock HTTP/1.0 
Content-Type: application/x-www-form-urlencoded 
Content-Length: 118 


stockApi=http://192.168.0.68/admin
```
