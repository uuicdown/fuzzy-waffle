# 横向权限升级发生在用户能够访问属于其他用户的资源，而非其自身该类型资源时。例如，如果员工可以访问其他员工的记录以及自己的记录，这就是横向权益升级。


# 水平权限升级攻击可能使用与垂直权限提升类似的利用方法。例如，用户可能通过以下 URL 访问自己的账户页面：

```
https://insecure-website.com/myaccount?id=123
```
# 如果攻击者将 `id` 参数值修改为另一用户的，可能会获得另一用户账户页面及相关数据和功能访问。

```
这是一个不安全的直接对象引用（IDOR）漏洞示例。当用户-控制器参数值被用来直接访问资源或函数时，就会出现这种漏洞。
```

# 在某些应用中，可利用参数没有可预测的值。例如，应用程序可能使用全局唯一标识符（GUID）来识别用户，而不是递增数字。这可能防止攻击者猜测或预测其他用户的标识符。然而，属于其他用户的 GUID 可能会在应用中被引用用户的其他地方披露，如用户消息或评论。
