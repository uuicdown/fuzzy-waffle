# 进入`robots.txt` 后可以看见机器人访问规则列表![[Pasted image 20261010125511.png]]
```
robots.txt
告诉爬虫机器人哪些可以爬哪些不能爬
Disallow：不要抓取的目录
allow：可以抓取的目录
Sitemap：告诉爬虫网站地图在哪里
```
