# 一些应用程序在登录时确定用户的访问权限或角色，并将这些信息存储在用户可控制的位置。这可能是：
- A hidden field.   一个隐藏的领域。
- A cookie.   一块饼干。
- A preset query string parameter.  一个预设的查询字符串参数。
# 应用程序根据提交的值做出访问控制决策。例如：
```
https://insecure-website.com/login/home.jsp?admin=true 
https://insecure-website.com/login/home.jsp?role=1
```
# 这种方法不安全，因为用户可以修改未被授权的值和访问功能，比如管理功能。
