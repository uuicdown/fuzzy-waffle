#  暴力破解攻击是指攻击者通过反复试验来猜测有效的用户凭证。这些攻击通常通过用户名和密码的单词列表进行自动化。通过自动化这一过程，尤其是使用专用工具，有可能使攻击者能够高速进行大量登录尝试。

# 暴力破解并不总是完全随机猜测用户名和密码。通过利用基本逻辑或公开知识，攻击者可以微调暴力破解攻击，做出更有根据的猜测。这大大提高了此类攻击的效率。依赖基于密码登录的唯一身份验证方式的网站，如果没有实施足够的暴力破解防护，可能会极易受到攻击。


# 然而，虽然高熵密码对单靠计算机来说很难破解，但我们可以利用对人类行为的基本了解，利用用户无意中引入该系统的漏洞。用户通常不会用随机字符组合创建强密码，而是取一个自己能记住的密码，试图用撬棍硬塞进密码策略中。例如，如果不允许使用 `mypassword`，用户可以尝试 `Mypassword1！` 或 `Myp4$$w 0rd` 这样的代码。

# 在政策要求用户定期更改密码的情况下，用户通常只需对其首选密码做一些小的、可预测的更改。例如，`Mypassword1！` 变成 `Mypassword1？` 或 `Mypassword2！`


# 这种对可能凭证和可预测模式的了解意味着暴力破解攻击往往比单纯地迭代所有可能字符组合更为复杂，因此更有效。
