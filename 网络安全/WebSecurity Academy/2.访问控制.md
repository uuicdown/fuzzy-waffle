# 是什么访问控制
访问控制是对谁或什么被授权执行动作或访问资源施加约束。在 Web 应用的语境中，访问控制依赖于身份验证和会话管理：
- **认证**确认用户身份就是他们所说的身份。
- **会话管理**识别同一用户正在发出的后续 HTTP 请求。
- **访问控制**决定用户是否被允许执行他们试图执行的操作。
访问控制失效很常见，且常常构成关键的安全漏洞。访问控制的设计和管理是一个复杂且动态的问题，涉及业务、组织和法律限制对技术实施的应用。访问控制的设计决策必须由人工做出，因此错误的可能性很高。

# 垂直越权 Vertical privilege escalation
如果用户能够访问他们不被允许访问的功能，这就是垂直特权升级。例如，如果非管理员用户能够访问管理员页面并删除用户账户，这就是垂直越权

## 未保护功能Unprotected functionality
最基本的垂直权限升级是指应用程序不对敏感功能进行任何保护。例如，管理功能可能从管理员的欢迎页面链接，但不链接用户的欢迎页面。不过，用户可能可以通过浏览到相关的管理员 URL 访问管理功能。

例如，一个网站可能托管在以下 URL 的敏感功能：
```
https://insecure-website.com/admin
```


这可能对任何用户开放，而不仅仅是管理员用户，他们在用户界面中链接到了该功能。在某些情况下，管理网址可能会在其他地方披露，例如 `robots.txt` 文件：

```
https://insecure-website.com/robots.txt
```

即使 URL 未公开，攻击者也可能利用词表暴力破解敏感功能的位置。
